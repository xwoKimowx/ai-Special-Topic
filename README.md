# 智生活——AI 輔助學習系統

高中專題作品，由本人獨立完成所有程式開發。

## 專案簡介

「智生活——AI 輔助學習系統」是一套以 AI 大型語言模型為核心的互動式學習平台，使用者可上傳題庫，由系統自動出題、批改並提供解析，協助學生提升學習效率。

## 技術架構

- **前端**：HTML / CSS / JavaScript，支援 PWA 安裝
- **後端**：Python + Flask，負責 API 金鑰安全管理
- **AI 串接**：透過 OpenRouter 呼叫 GPT-4o-mini 語言模型
- **行動裝置**：封裝為 Android APK，可直接安裝於手機

## 主要功能

- 上傳自訂題庫（.txt 格式），系統自動解析題目
- AI 即時出題、評分與解題說明
- 學習紀錄與答題統計
- 支援 PWA 安裝與 Android APK

## 版本歷程

從 v1.0 開發至 v1.73，共歷經 70 餘次版本迭代，所有程式碼均由本人獨立撰寫。
